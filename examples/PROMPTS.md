# Example Prompts for Minecraft Builder

Use these prompts when chatting with Claude (with the MCP server installed) to generate Minecraft structures.

## Basic Structures

### Platforms and Foundations
```
Create a 5x5 stone platform
```

```
Build a circular stone foundation, 7 blocks in diameter
```

```
Make a wooden deck, 10x8 blocks, using oak planks
```

### Simple Buildings
```
Build a small wooden shed: 5x5 blocks, 4 blocks tall, oak planks walls with a flat roof
```

```
Create a stone watchtower: 3x3 base, 12 blocks tall, with small windows every 3 blocks
```

```
Make a cozy cottage: 8x6 blocks, oak planks walls, stone foundation, glass windows
```

## Intermediate Structures

### Walls and Fences
```
Build a stone wall section: 10 blocks long, 3 blocks tall, with cobblestone
```

```
Create a castle wall segment with battlements: 15 blocks long, 8 blocks tall
```

### Gardens and Outdoor
```
Design a small garden: cobblestone path down the middle (1 block wide, 10 blocks long),
with dirt blocks on each side for planting
```

```
Create a campfire area: circular arrangement of logs around a center block,
8 blocks diameter
```

### Bridges
```
Build a simple wooden bridge: 2 blocks wide, 12 blocks long, oak planks with
oak fence railings on each side
```

```
Make a stone arch bridge: 4 blocks wide, spans 10 blocks, with cobblestone
```

## Advanced Structures

### Towers
```
Build a lighthouse: circular base (diameter 7 blocks), 25 blocks tall,
stone for bottom 20 blocks, glass for top 5 blocks, with spiral windows
```

```
Create a wizard tower: 5x5 base, 20 blocks tall, stone bricks,
wooden floor every 5 blocks
```

### Houses
```
Design a two-story house:
- First floor: 10x8 blocks, stone foundation, oak planks walls
- Windows: glass panes on all sides
- Second floor: same size, wooden floor
- Roof: sloped using stairs or planks
```

```
Build a medieval inn:
- Ground floor: 12x8 blocks, cobblestone walls, large oak door entrance
- Second floor: 12x8 blocks, oak planks, multiple rooms
- Roof: dark oak planks, pitched roof
```

### Decorative
```
Create a fountain: 5x5 circular base with stone bricks, 3 blocks tall in center
with water, surrounded by stone brick stairs
```

```
Build a statue: humanoid figure, 3 blocks wide, 8 blocks tall,
made of quartz blocks
```

```
Make a gazebo: 6x6 octagonal shape, 5 blocks tall, oak wood frame with
decorative roof
```

## Tips for Better Results

1. **Be specific about dimensions**: "5x5 blocks" or "10 blocks tall"

2. **Specify materials**: "oak planks", "cobblestone", "glass panes"

3. **Describe the structure**: Mention floors, walls, roof, windows

4. **Use cardinal directions**: "windows on north and south sides"

5. **Include details**: "with a door in the center", "spiral staircase inside"

6. **Reference real structures**: "like a medieval castle keep" or "Japanese pagoda style"

## Block Type Reference

Common block types to use in your prompts:

**Stone types:**
- `stone`, `cobblestone`, `stone_bricks`, `smooth_stone`
- `granite`, `diorite`, `andesite`

**Wood types:**
- `oak_planks`, `oak_log`, `oak_stairs`, `oak_slab`
- `spruce_planks`, `birch_planks`, `jungle_planks`
- `dark_oak_planks`, `acacia_planks`

**Building materials:**
- `glass`, `glass_pane`
- `brick`, `bricks`
- `sandstone`, `red_sandstone`
- `quartz_block`

**Decorative:**
- `glowstone`, `sea_lantern` (lighting)
- `fence`, `oak_fence`, `iron_bars`
- `door`, `oak_door`, `iron_door`

**Natural:**
- `dirt`, `grass_block`, `gravel`, `sand`
- `water`, `lava`
- `leaves`, `oak_leaves`
